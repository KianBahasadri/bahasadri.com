# Bahasadri.com 🎀💻

A fully vibe-coded personal application with different features. Each feature is as silod as possible from other features, this makes it easier for an LLM to work with.
No tenant seperation or staging environment, whole thing is blocked off by cloudflare zero trust and only accessible by me.
It follows a document driven approach, in other words I write what I want and the ai spits out the code.
Yes I've had to restructure multiple times but each attempt honestly has taken me further.

Current restructure:

1. I alone write a single markdown document at /docs/features/[feature-name].md
    - Purely english prose
    - User features
    - Architecture and design
    - Mentions of libraries and etc.
2. I work _with_ an LLM to create schemas at /docs/schemas/[feature-name]/
    - OpenApi yaml file, checked by `spectral lint` using oas spec
    - Prisma schema, checked by `prisma validate`
    - Typescript types, generated by `openapi-typescript-codegen`
    - Generate test scenarios in markdown, document cannot exceed 1000 words
3. LLM alone generates tests at /backend/tests/[feature-name]/ and /frontend/tests/[feature-name]/
    - written scenarios -> vitest tests
4. LLM alone generates all the code at /backend/src/[feature-name]/ and /frontend/src/pages/[feature-name]/
    - No human oversight
5. Automated testing suite
    - Run `Schemathesis`
    - Run vitest tests
